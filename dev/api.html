Krang._Gϕt Function
julia
_Gϕt(
    pix::Krang.AbstractPixel,
    θs,
    isindir,
    n
) -> Tuple{Any, Any, Bool}

Returns (Gϕ, Gt, issuccess): the ϕ and t angular antiderivatives of Gϕ and Gt for the same emission inclination.

Both share the whole angular setup — η, λ, the turning points up/um, the modulus k and the amplitude asin(args) — and differ only in which elliptic integral they evaluate at that amplitude. The emission_coordinates methods always want both, so computing the setup once avoids doing it twice. Results are bit-identical to calling Gϕ and Gt separately.

Krang._absGθo_Gθhat Function
julia
_absGθo_Gθhat(metric::Kerr{T}, θo, η, λ) -> Tuple{Any, Any}

Returns (|Gθo|, Ĝθ): the magnitude of the Gθ antiderivative evaluated at the observer inclination, and the half-period Ĝθ between angular turning points.

Both depend only on the metric, θo, η and λ, so they are constant along a ray and are cached on the pixel – see Krang.absGθo_Gθhat for the accessor. Every sub-image index n reuses the same pair, which is what makes the angular inversion cheap.

Krang.jac_fluid_u_zamo_d Function
julia
jac_fluid_u_zamo_d(_::Kerr{T}, β, θ, φ) -> Any

Returns the Jacobian that takes the ZAMO vector into the frame of a fluid moving with speed β along the direction (θ, φ). Pass -β for the inverse boost.

The Jacobian is:

    γ            -βγcosφsinθ                   -βγsinφsinθ                -βγcosθ
    -βγcosφsinθ  cos²θcos²φ+γcos²φsin²θ+sin²φ  (γ-1)cosφsin²θsinφ         (γ-1)cosθcosφsinθ
    -βγsinθsinφ  (γ-1)cosφsin²θsinφ            cos²φ+(cos²θ+γsin²θ)sin²φ  (γ-1)cosθsinθsinφ
    -βγcosθ      (γ-1)cosθcosφsinθ             (γ-1)cosθsinθsinφ          γcos²θ+sin²θ
source
julia
jac_fluid_u_zamo_d(_::Kerr{T}, β, θ, φ, v_u) -> Any

Returns the ZAMO vector in the frame of a fluid moving with speed β along the direction (θ, φ). Pass -β for the inverse boost.

Applies the Jacobian above without forming it. Its spatial block is δᵢⱼ + (γ-1)n̂ᵢn̂ⱼ for n̂ = (sin(θ)cos(φ), sin(θ)sin(φ), cos(θ)), so the product is the boost γ(vᵗ - β n̂⋅v⃗), v⃗ + ((γ-1)n̂⋅v⃗ - γβvᵗ)n̂.

Krang.p_zamo_u Function
julia
p_zamo_u(
    metric::Kerr{T},
    r,
    θ,
    η,
    λ,
    νr::Bool,
    νθ::Bool
) -> Any

Returns the photon momentum in the ZAMO basis.

Composes p_bl_d, metric_uu and jac_zamo_u_bl_d. The frame-dragging term the metric puts into p^ϕ is the one the tetrad subtracts off again, so the composition is:

    p^t̂ = (1 - ωλ)/α
    p^r̂ = ±√R/√(ΣΔ)
    p^ϕ̂ = λ/ϖ
    p^θ̂ = ∓√Θ/√Σ

with lapse α = √(ΣΔ/A), frame-dragging rate ω = 2ar/A and cylindrical radius ϖ = sin(θ)√(A/Σ).

Krang.ThermalSynchrotron Type
julia
struct ThermalSynchrotron{N, T} <: Krang.AbstractMaterial

A synchrotron emitting disk of thermal (Maxwell-Jüttner) electrons whose density, temperature and magnetic field each follow a power law in radius. Emission is absorbed on its way out, so the material returns a Krang.AbsorptiveIntensity and render performs the radiative transfer across sub-images.

Follows the model of Desire, Cárdenas-Avendaño & Chael (2025) (their eqs. 13-14), with the thermal synchrotron integral replaced by the Krang.thermal_synchrotron_shape approximation,

jν=kenthqe2ν23Θe2I(ν/νc),νc=34πqeBsin⁡θbmeΘe2,Θe=kBTemec2,

with absorption set by Kirchhoff's law, αν=jν/Bν, and an optical depth τ=ανℓ/c. The ray crosses a shell of angular thickness Δθ=1/2 about the emitting 2D surface, so ℓ=(rsrg/2)ℓp with ℓp=|pt^/pθ^|, the obliquity of the ray to the surface normal θ^. This quantity diverges for a ray traveling parallel to the emitting surface. Note the proper thickness is gθθΔθ=rs2+a2cos2⁡θsΔθ to first order in Δθ, so taking it to be rsrgΔθ is exact only for the equatorial disk; the depth through a cone is underestimated by 1+a2cos2⁡θs/rs2, which reaches a few per cent close to the horizon.

The emissivity is evaluated at the observed frequency and the result is redshifted by g3.

Radii are in gravitational radii and rg is specified in metres. Every other quantity is SI except for the magnetic field, which is in Gauss.

Fields

- `magnetic_field::SVector{3, T}`: Magnetic field vector `(x, y, z)` at `rb`, in Gauss.
- `fluid_velocity::SVector{3, T}`: Fluid velocity `(speed, inclination, azimuth)`.
- `p_dens::T`: Power-law index of the number density.
- `p_temp::T`: Power-law index of the electron temperature.
- `p_b::T`: Power-law index of the magnetic field magnitude.
- `n_th0::T`: Number density at `rb`, in m⁻³.
- `t_e0::T`: Electron temperature at `rb`, in K.
- `rb::T`: Reference radius, in gravitational radii.
- `ν::T`: Observed frequency, in Hz.
- `rg::T`: Gravitational radius `GM/c²`, in metres.
- `subimgs::NTuple{N, Int}`: The sub-images to ray trace.

Screen of slow-light pixels, stored as a struct of arrays: one array per cached geodesic invariant rather than one SlowLightIntensityPixel per screen position.

metric and the inclination θo are constant across the screen, so they are held once here instead of being duplicated into every pixel. SlowLightIntensityPixel is lazily constructed when screen.pixels is indexed. This layout is what allows the cached invariants to cross a Reactant.@compile boundary as data.
