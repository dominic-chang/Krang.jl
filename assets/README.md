# Assets

## `bunny.obj`

The Stanford bunny, used by `test/mesh_geometry_tests.jl` and
`examples/ray-tracing-mesh-example.jl` as a triangular mesh to ray trace. 2503 vertices,
4968 faces.

The original model is from the [Stanford 3D Scanning
Repository](https://graphics.stanford.edu/data/3Dscanrep/) (Greg Turk and Marc Levoy,
1994); please acknowledge Stanford if you reuse it.
